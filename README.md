# danesamo.github.io

Personal portfolio of Daniela Samo, Data & AI Engineer.

Live at **https://danesamo.github.io**

## Stack

- [Astro](https://astro.build) for a fast, static multi-page site
- [Tailwind CSS](https://tailwindcss.com) for styling
- GitHub Actions and GitHub Pages for deployment on every push to `main`

## Run locally

```sh
npm install
npm run dev
```

## Update the content

All projects, experience and certifications live in `src/data/site.ts`. Edit that file and push: the site rebuilds automatically.
